## 4. v1.0.0の公開条件

1. 重大・中の未解決不具合ゼロ。
2. 既存47件＋全10シナリオのE2Eが合格。
3. 39対策の判定根拠・作用点・効果限界の整合。既存39/39テスト結果を正しく引用し、必要なら再実行可能な回帰テストをリポジトリに組み込む。
4. QA-REPORTを最新版の結果へ更新し、過去の結果は削除しない。
5. ソースZIPの目的（閲覧用最小構成／検証再現用一式）を確定して、READMEの説明と実際の内容を一致させる。
6. 代表画面の視覚レビュー、公開サイトのバージョン・起動・比較・初期化の確認。
7. 要件合格後にv1.0.0への変更を別PRで実施し、Pagesの公開履歴を確認する。

## 5. 判定を保留する理由

v0.5.43はすでに公開されており大きな改修は不要。ただし、正式版を名乗るなら、**テストの再現性、配布内容と文書の一貫性、公開後の代表操作**まで証拠を揃える方がよい。結果を「未実施・不合格・合格」に区別し、未確認を合格として扱わない。
